# ============================================================
# Fall Guardian - 구형 Jetson Nano (4GB) 전용 의존성
# ============================================================
# 대상 환경: JetPack 4.6.x (L4T R32.7.x, Ubuntu 18.04, CUDA 10.2,
#            TensorRT 8.2.1, cuDNN 8.2)
#
# 주의사항:
#   1. JetPack 4.6.x 기본 Python은 3.6.9이며, numpy>=1.24/scipy>=1.10/
#      openai-whisper 등 최신 패키지는 Python 3.6을 지원하지 않는다.
#      반드시 Python 3.8(소스 빌드 또는 community wheel)을 사용할 것.
#      (scripts/setup_jetson_nano.sh 참고)
#   2. torch/torchvision은 PyPI가 아닌 NVIDIA Jetson 전용 wheel을 사용한다.
#      https://forums.developer.nvidia.com/t/pytorch-for-jetson 페이지에서
#      JetPack 4.6.x + Python 3.8 조합 wheel을 받아 설치한다.
#      (pip install <다운로드한 .whl 경로>)
#   3. tensorrt/pycuda/onnxruntime은 PyPI에 aarch64+Jetson 빌드가 없으므로
#      JetPack에 포함된 시스템 패키지(/usr/lib/python3.6/dist-packages 등)를
#      venv에서 그대로 참조하도록 --system-site-packages 로 venv를 만들고,
#      pycuda만 소스 빌드한다. 아래 패키지 목록에서 tensorrt는 제외되어 있다.
#
# 설치: pip install -r requirements-jetson-nano.txt
# ============================================================
